🔔 วิธีติดตั้งการแจ้งเตือน LINE และอีเมล

เมื่อนักวิจัยกดส่งคำขอผ่านแบบฟอร์ม ระบบจะแจ้งเตือนสัตวแพทย์ทันที 3 ทางพร้อมกัน
ช่องทางสิ่งที่ได้รับ
📱 LINE OAข้อความสรุปคำขอ ชื่อผู้ขอ รายการยา และคำเตือนถ้ายื่นกระชั้น
📧 อีเมลรายละเอียดครบทุกช่อง พร้อมตารางรายการยาและปุ่มเปิดระบบ
📊 Google Sheetsบันทึกลงชีตอัตโนมัติ (ไม่บังคับ — เปิดใช้ก็ได้ ไม่เปิดก็ได้)
ใช้เวลาประมาณ 30–40 นาที ทำครั้งเดียวจบ
ค่าใช้จ่ายไม่มี — ทั้ง LINE OA และ Google Apps Script ใช้แพ็กเกจฟรี
ต้องมีบัญชี LINE · บัญชี Google · สิทธิ์แก้ไขรีโป GitHub

ระบบทำงานอย่างไร

นักวิจัยกดส่งคำขอ │ ├──→ Firebase (บันทึกคำขอ — ทำงานเสมอ) │ └──→ แท็บ "คำขอเข้าใหม่" ของสัตวแพทย์ │ └──→ Google Apps Script (ตัวกลางแจ้งเตือน) ├──→ LINE Official Account ├──→ อีเมล └──→ Google Sheets (ถ้าเปิดใช้)
ทำไมต้องมีตัวกลาง ไม่ส่ง LINE ตรงจากหน้าเว็บ
การส่ง LINE ต้องใช้ Channel Access Token ซึ่งเป็นกุญแจที่ส่งข้อความในนาม OA ได้ ถ้าฝังไว้ในหน้าเว็บ ใครเปิดดูโค้ดหน้าเว็บก็เห็นและนำไปใช้ได้ทันที Google Apps Script รันอยู่บนเครื่องของ Google จึงเก็บกุญแจไว้ได้อย่างปลอดภัย
ระบบไม่ขึ้นกับการแจ้งเตือน — ถ้า Apps Script ล่มหรือยังไม่ได้ตั้งค่า คำขอยังบันทึกลง Firebase และขึ้นในแท็บ “คำขอเข้าใหม่” ตามปกติทุกประการ การแจ้งเตือนเป็นของแถม ไม่ใช่เส้นทางหลักของข้อมูล
หมายเหตุ — LINE Notify ปิดให้บริการแล้วตั้งแต่ 31 มีนาคม 2568 จึงต้องใช้ LINE Official Account ร่วมกับ Messaging API แทน ซึ่งเป็นวิธีที่คู่มือนี้ใช้

ส่วนที่ 1  สร้าง LINE Official Account

1สร้างบัญชี LINE OA

  1. เปิด manager.line.biz → ลงชื่อเข้าใช้ด้วยบัญชี LINE ของท่าน
  2. กด สร้างบัญชีใหม่ (Create new account)
  3. กรอกข้อมูล
    • ชื่อบัญชี เช่น PSU LASC บริการยาและเวชภัณฑ์
    • ประเภทธุรกิจ เลือกการศึกษา หรือใกล้เคียง
  4. กด สร้างบัญชี — จะได้ OA แบบฟรีทันที ไม่ต้องยืนยันตัวตน

2เปิด Messaging API

  1. ใน LINE OA Manager → เมนู ตั้งค่า (Settings) มุมขวาบน
  2. เมนูซ้าย → Messaging API
  3. กด ใช้ Messaging API (Enable Messaging API)
  4. เลือก Provider — ถ้ายังไม่มี ให้สร้างใหม่ ตั้งชื่อเช่น PSU LASC
  5. กด ตกลง จนจบ
Provider คือ “เจ้าของแอป” ในระบบของ LINE สร้างครั้งเดียวใช้ได้กับทุก OA ของหน่วยงาน

3ออก Channel Access Token

  1. เปิด developers.line.biz/console
  2. เลือก Provider ที่สร้างไว้ → เลือก Channel ของ OA นี้
  3. แท็บ Messaging API → เลื่อนลงล่างสุดหา Channel access token (long-lived)
  4. กด Issue → จะได้ข้อความยาวมาก กดคัดลอกเก็บไว้
🔑 token นี้คือกุญแจ ห้ามส่งให้ใคร ห้ามวางในหน้าเว็บ ห้าม commit ขึ้น GitHub
ใช้วางในขั้นที่ 5 เท่านั้น ซึ่งเก็บไว้ฝั่ง Google ไม่ปรากฏต่อผู้ใช้เว็บ
ถ้าเผลอหลุดออกไป ให้กลับมาที่หน้านี้แล้วกด Reissue เพื่อยกเลิกตัวเก่าทันที

4เพิ่ม OA เป็นเพื่อน และปิดข้อความตอบกลับอัตโนมัติ

⚠ ขั้นนี้ห้ามข้าม — ระบบส่งแบบ broadcast คือส่งถึงทุกคนที่เป็นเพื่อนกับ OA ถ้าไม่มีใครเป็นเพื่อนเลย ข้อความจะไม่ถึงใคร
  1. กลับไปที่ LINE OA Manager → หน้า โฮม
  2. หา QR code เพิ่มเพื่อน หรือลิงก์ line.me/R/ti/p/@...
  3. ให้สัตวแพทย์และผู้เกี่ยวข้องทุกคนสแกนเพิ่มเป็นเพื่อน
  4. แนะนำให้ปิดข้อความอัตโนมัติ เพื่อไม่ให้รบกวน
    • ตั้งค่า → การตอบกลับ → ปิด ข้อความต้อนรับ และ ตอบกลับอัตโนมัติ
✅ ใครเพิ่มเป็นเพื่อนก็ได้รับแจ้งเตือน — เพิ่มคนทีหลังได้ตลอด ไม่ต้องแก้โค้ดใด ๆ

ส่วนที่ 2  ตั้งค่า Google Apps Script

5สร้างโปรเจกต์และวางโค้ด

  1. เปิด script.google.com → ลงชื่อเข้าใช้ด้วยบัญชี Google
  2. กด New project
  3. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) ว่า PSU LASC แจ้งเตือนคำขอซื้อยา
  4. ลบโค้ดตัวอย่างใน Code.gs ออกให้หมด
  5. เปิดไฟล์ line-email-notify.gs ในโฟลเดอร์ระบบด้วย Notepad → คัดลอกทั้งไฟล์ → วางลงไปแทน
  6. กด 💾 Save

6ใส่ค่าตั้งต้นแล้วรันหนึ่งครั้ง

เลื่อนหาฟังก์ชัน ตั้งค่าครั้งแรก() ใกล้ ๆ ด้านบนของไฟล์ แล้วแก้ 4 ค่านี้

LINE_TOKEN:    'วาง token จากขั้นที่ 3 ตรงนี้'
VET_EMAIL:     'kwanchanok.d@psu.ac.th'
NOTIFY_SECRET: 'lasc-med-8f3kqz91'      ← ตั้งเองให้เดายาก จำไว้ใช้ขั้นที่ 9
SHEET_ID:      ''                        ← เว้นว่างไว้ก่อนได้
  1. กด 💾 Save
  2. ช่องเลือกฟังก์ชันด้านบน เลือก ตั้งค่าครั้งแรก
  3. กด ▶ Run
  4. ครั้งแรกจะขึ้นหน้าขออนุญาต → Review permissions → เลือกบัญชี Google ของท่าน
  5. ถ้าขึ้นหน้าเตือน Google hasn't verified this app
    กด Advanced → Go to … (unsafe) → Allow
    คำเตือนนี้เป็นเรื่องปกติของสคริปต์ที่เขียนเอง เพราะยังไม่ได้ส่งให้ Google ตรวจสอบ — ท่านเป็นผู้เขียนและเจ้าของสคริปต์เอง จึงปลอดภัย
  6. ดูช่อง Execution log ด้านล่าง ต้องขึ้นว่า บันทึกการตั้งค่าเรียบร้อยแล้ว
✅ ค่าทั้ง 4 ถูกเก็บใน Script Properties ซึ่งอยู่ฝั่งเซิร์ฟเวอร์ของ Google ไม่ปรากฏในหน้าเว็บ และไม่ติดไปกับโค้ดที่อัปขึ้น GitHub

7ทดสอบก่อนใช้งานจริง

  1. ช่องเลือกฟังก์ชัน เลือก ทดสอบการแจ้งเตือน
  2. กด ▶ Run
  3. ภายในไม่กี่วินาทีควรได้รับ
    • 📱 ข้อความ LINE จาก OA ที่สร้างไว้
    • 📧 อีเมลหัวข้อ 📥 คำขอซื้อยาใหม่ REQ-…-TEST
  4. ดู Execution log จะบอกผลแต่ละช่องทาง เช่น LINE : sent
ถ้า log ขึ้น LINE : http 401 แปลว่า token ผิด — กลับไปคัดลอกใหม่จากขั้นที่ 3
ถ้าขึ้น skipped แปลว่ายังไม่ได้ใส่ค่า — กลับไปทำขั้นที่ 6 ใหม่

8เผยแพร่เป็น Web App

  1. มุมขวาบน กด Deploy → New deployment
  2. กดไอคอน ⚙️ ข้างคำว่า Select type → เลือก Web app
  3. ตั้งค่าดังนี้
    Descriptionแจ้งเตือนคำขอซื้อยา v1
    Execute asMe (บัญชีของท่าน)
    Who has accessAnyone
  4. กด Deploy → อนุญาตสิทธิ์อีกครั้งถ้าถาม
  5. คัดลอก Web app URL หน้าตาแบบนี้ 
    https://script.google.com/macros/s/AKfycb...ยาวมาก.../exec
ทำไมต้องเลือก Anyone — เพราะแบบฟอร์มของนักวิจัยเรียกมาโดยไม่ได้ล็อกอิน Google ความปลอดภัยมาจาก NOTIFY_SECRET ที่ตั้งไว้ในขั้นที่ 6 ซึ่งสคริปต์ตรวจทุกครั้ง ถ้ารหัสไม่ตรงจะไม่ส่งอะไรเลย
ทุกครั้งที่แก้โค้ดในสคริปต์ ต้องกด Deploy → Manage deployments → ✏️ แก้ไข → Version: New version → Deploy ด้วย ไม่งั้นระบบยังใช้โค้ดเวอร์ชันเก่า

ส่วนที่ 3  เชื่อมเข้ากับระบบ

9ใส่ค่าใน firebase-config.js

เปิดไฟล์ firebase-config.js ด้วย Notepad เลื่อนลงล่างสุด หา 2 บรรทัดนี้

window.NOTIFY_WEBHOOK_URL = '';
window.NOTIFY_SECRET = '';

แก้เป็น

window.NOTIFY_WEBHOOK_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
window.NOTIFY_SECRET = 'lasc-med-8f3kqz91';
⚠ NOTIFY_SECRET ต้องตรงกันเป๊ะกับที่ใส่ในขั้นที่ 6 ตัวพิมพ์เล็กใหญ่ก็ต้องตรง ถ้าไม่ตรง สคริปต์จะปฏิเสธและไม่ส่งแจ้งเตือน
บันทึกไฟล์เป็น UTF-8 และอย่าลืมเครื่องหมาย ' ครอบค่า กับ ; ท้ายบรรทัด

10อัปโหลดและทดสอบจริง

  1. อัปโหลด firebase-config.js และ request.html ขึ้น GitHub (Add file → Upload files → Commit changes)
  2. รอ 1–2 นาที
  3. เปิด https://kwanchanokd.github.io/psu-lasc-medicine/request.html แล้วกด Ctrl + Shift + R
  4. กรอกข้อมูลทดสอบ → กด 📨 ส่งคำขอ
  5. ตรวจผลทั้ง 4 อย่าง
    • ได้รหัสอ้างอิง REQ-… บนหน้าจอ
    • 📱 ได้ข้อความ LINE
    • 📧 ได้อีเมล
    • คำขอโผล่ในแท็บ 📥 คำขอเข้าใหม่ ของระบบหลัก
  6. ลบคำขอทดสอบด้วยปุ่ม ✖ ตีกลับ / ลบ
✅ ครบทั้ง 4 ข้อ = ติดตั้งสมบูรณ์

📊 เปิดใช้การบันทึกลง Google Sheets (ไม่บังคับ)

  1. สร้างสเปรดชีตใหม่ที่ sheets.new ตั้งชื่อเช่น ทะเบียนคำขอซื้อยา
  2. ดูลิงก์บนแถบที่อยู่ คัดลอกส่วนกลางที่เป็น ID 
    docs.google.com/spreadsheets/d/1AbC...ตรงนี้คือ ID...XyZ/edit
  3. กลับไปที่ Apps Script → แก้ SHEET_ID ในฟังก์ชัน ตั้งค่าครั้งแรก() ให้เป็น ID นั้น
  4. กด 💾 Save → เลือกฟังก์ชัน ตั้งค่าครั้งแรก → ▶ Run อีกครั้ง
  5. ทดสอบด้วย ทดสอบการแจ้งเตือน → จะมีแถวใหม่โผล่ในชีตชื่อ คำขอ
ระบบสร้างหัวตาราง 15 คอลัมน์ให้อัตโนมัติในครั้งแรก และเปิดไฟล์นี้ด้วย Excel ได้ (ไฟล์ → ดาวน์โหลด → Microsoft Excel)

🔧 แก้ปัญหาที่พบบ่อย

อาการสาเหตุและวิธีแก้
ส่งคำขอได้ แต่ไม่ได้รับอะไรเลย ยังไม่ได้อัปโหลด firebase-config.js ที่แก้แล้วขึ้น GitHub หรือลืมกด Ctrl+Shift+R — ลองเปิด Web app URL ด้วยเบราว์เซอร์ ต้องเห็นข้อความ “✅ ตัวกลางแจ้งเตือนทำงานปกติ”
ได้อีเมล แต่ไม่ได้ LINE ยังไม่ได้เพิ่ม OA เป็นเพื่อน (ขั้นที่ 4) หรือ token ผิด — รัน ทดสอบการแจ้งเตือน แล้วดู Execution log
ได้ LINE แต่ไม่ได้อีเมล ตรวจกล่องขยะ (Junk) ก่อน · ตรวจว่าสะกด VET_EMAIL ถูกต้อง
log ขึ้น LINE : http 401 Channel access token ผิดหรือถูกยกเลิก — ออก token ใหม่ในขั้นที่ 3 แล้วรัน ตั้งค่าครั้งแรก อีกครั้ง
log ขึ้น LINE : http 429 ส่งเกินโควตาข้อความรายเดือนของ LINE OA — รอเดือนถัดไป หรืออัปเกรดแพ็กเกจ (ปกติไม่มีทางถึงที่ปริมาณงานระดับนี้)
สคริปต์ตอบ unauthorized NOTIFY_SECRET สองฝั่งไม่ตรงกัน — เทียบตัวพิมพ์เล็กใหญ่ให้เหมือนกันเป๊ะ
แก้โค้ดแล้วไม่มีผล ลืม Deploy เวอร์ชันใหม่ — Deploy → Manage deployments → ✏️ → Version: New version → Deploy

🔒 ข้อควรรู้ด้านความปลอดภัย

  • Channel access token ของ LINE อยู่ใน Script Properties ฝั่ง Google เท่านั้น ไม่ปรากฏในหน้าเว็บ และไม่ติดไปกับไฟล์ที่อัปขึ้น GitHub
  • NOTIFY_SECRET ปรากฏในหน้าเว็บ (เพราะอยู่ใน firebase-config.js) จึงไม่ใช่ความลับระดับสูง หน้าที่ของมันคือกันการยิงข้อมูลขยะแบบสุ่มเท่านั้น หากหลุดออกไป ผลเสียสูงสุดคือมีคนส่งแจ้งเตือนปลอมมารบกวน ไม่สามารถอ่านข้อมูลคำขอหรือส่งข้อความในนาม OA ได้
  • ถ้าถูกรบกวน ให้เปลี่ยน NOTIFY_SECRET ทั้งสองฝั่งเป็นค่าใหม่
  • ข้อมูลที่ส่งผ่านตัวกลางมีข้อมูลส่วนบุคคลของนักวิจัย (ชื่อ อีเมล โทรศัพท์ และเลขประจำตัวผู้เสียภาษีถ้ากรอก) — ใช้บัญชี Google ของหน่วยงานหรือของผู้รับผิดชอบโดยตรง ไม่ควรใช้บัญชีที่แชร์กับผู้อื่น
